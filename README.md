### 🟠 About Me

Я администратор и специалист технической поддержки в студии **KNICE TECH & MINICE**, занимающейся разработкой десктопных голосовых помощников. Моя работа находится на стыке системного программирования, обеспечения качества (QA) и создания расширяемой архитектуры через плагины. 

Особое внимание я уделяю созданию **современных, визуально отполированных интерфейсов** (с эффектами blur, адаптивными темами и высококачественными интерактивными компонентами в духе iOS). В свободное время развиваю open-source инициативы и работаю над кроссплатформенными утилитами для Windows и Linux с фокусом на чистый код и минимальное потребление ресурсов.
